Eight skills

The skills

A skill is a decision procedure your agent runs with you: the questions in order, the checks that have to pass, and the exit that says this one cannot be answered. Eight of them, one for each position on the method map.

Routing

routing-questions

Whether this becomes work at all, and which skill it becomes.

 The floor

defining-metrics

A metric turned into a computation, a source of truth, and a statement of how it will be gamed.

 Description

sizing-opportunities

A what-happened question turned into a localised, sized hypothesis, with the floor checked first and the gap never quoted as the prize.

 Causation

designing-experiments

The four choices that cannot be repaired after launch, with the MDE from the prior store.

 Causation

reading-experiments

Whether the result is a result: SRM, exposure, the sequential bound, CUPED, shrinkage.

 Causation

choosing-causal-designs

The method that matches how assignment happened, and the exit that says there is no comparison group.

 Prediction

automating-decisions

Whether a repeated decision belongs to a model, validated out of time, and the holdout that measures its impact.

 The ceiling

writing-readouts

The decision rule first, the result last; the belief filed where the next question starts.

Each skill covers one position on the method map and one failure mode. Together they run one question end to end: it arrives at routing-questions, stands on the floor defining-metrics maintains, gets its method from designing-experiments or choosing-causal-designs, is believed or not by reading-experiments, and is filed by writing-readouts so the next question starts smaller. A what-happened question leaves the path for sizing-opportunities and comes back as a sized hypothesis; a decision made continuously, at volume, leaves it for automating-decisions and comes back for the experiment that measures the model's impact.

gallop

Route the question before it becomes an analysis. Product data science as agent skills, with a Python package underneath.
