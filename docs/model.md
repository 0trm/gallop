# License, data and contributions

Everything in this repository is open source under the

## Your data

gallop is markdown. It runs no code, makes no network calls and stores nothing;
whatever your agent does with a skill happens in your own project.

## Contributions

gallop is open source, not open contribution. Bug reports and ideas are welcome
as issues; pull requests from outside the project are not accepted. See
[CONTRIBUTING.md](../CONTRIBUTING.md).
