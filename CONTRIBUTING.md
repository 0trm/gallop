# Contributing

gallop is open source, not open contribution. Everything is MIT: use it, fork it
and change it for your own work. This repository takes changes only from its
collaborators.

## Issues

Bug reports and ideas are welcome as issues. Pick the template that fits:

- **Bug**: a skill misroutes, contradicts itself, or gets a number wrong.
- **Method dispute**: a check, threshold or recommendation in the skills is
  wrong. Bring the evidence: a derivation, a simulation, a published source.
- **Skill proposal**: a new skill, or a substantial extension of an existing one.

## Pull requests

Only collaborators can open pull requests here. To change gallop for your own
use, fork it; the [MIT license](LICENSE) allows it.
